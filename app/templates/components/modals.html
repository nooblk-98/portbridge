Peer settings

Separate entries with commas or spaces. A bare host address is saved as /32, and host bits are cleared, so 10.0.0.5/24 is saved as 10.0.0.0/24.

Access per route

Routes left on All peers are open to every connected peer. Choosing Selected peers with nothing ticked blocks the route for everyone.

On: only VPN and advertised-route traffic uses the tunnel, so the device keeps its own internet connection and IP address. Off (full tunnel): all of its internet traffic goes through the PortBridge hosted server and shows that server's IP address.

On: Docker containers and other traffic forwarded through the PortBridge server, such as a reverse proxy, can connect to the services running on this peer and the networks it advertises. Off (the default): they cannot. Other peers can still reach it over the tunnel (route access applies to advertised networks) and forwarded public ports still work. Programs run directly on the server (a shell, curl, ssh) are not restricted by this switch. The device's profile does not change.

DNS and MTU are optional: leave them blank to use the defaults. A keepalive of 25 seconds keeps the tunnel open behind NAT, and 0 turns it off.

Saving rewrites this peer's profile. It applies only after the device imports it; export status is recorded on the Routes tab.
